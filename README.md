# Гера — голосовой ИИ-ассистент в наушниках (Android)

Нажали кнопку на наушниках → пискнуло → задали вопрос → ИИ коротко ответил голосом.

## Как получить APK через GitHub

1. Создайте на GitHub новый репозиторий (можно приватный).
2. Загрузите в него **всё содержимое** этой папки (Add file → Upload files, перетащите файлы и папки).
   Важно, чтобы загрузилась папка `.github` — в ней файл автосборки.
3. Откройте вкладку **Actions** — сборка запустится сама (около 3–5 минут).
4. Когда появится зелёная галочка, откройте сборку и внизу в разделе **Artifacts** скачайте `Gera-apk`.
   Внутри zip лежит `app-debug.apk` — его и устанавливаете на телефон (разрешите установку из неизвестных источников).

Если вкладка Actions пустая — значит `.github` не загрузилась. Создайте файл вручную:
Add file → Create new file, имя `.github/workflows/build.yml`, вставьте содержимое из архива.

## Настройка в приложении

- **Адрес API** — базовый адрес OpenAI-совместимого API, например `https://api.example.com/v1`
  (`/chat/completions` приложение добавит само).
- **API-ключ** и **модель** — от вашего провайдера.
- **Системный промт** — как Гера должна отвечать.
- **Макс. длина ответа** — ограничение в токенах (200 ≈ пара предложений с запасом).
- **Скорость речи** — 1.00 обычная.
- **Погода** — модель сама запрашивает погоду через Open-Meteo. Если провайдер не поддерживает
  tool calling, приложение автоматически повторит запрос без инструментов.

## Как пользоваться

1. Включите тумблер «Ассистент включён» (разрешите микрофон и уведомления).
2. Нажмите кнопку пауза/воспроизведение на наушниках → короткий сигнал → говорите.
3. Повторное нажатие во время ответа — прервать.
4. В уведомлении есть кнопки «Спросить» и «Выключить».

## Ограничения

- Кнопки наушников Android отдаёт приложению, которое **последним играло звук**.
  Если после включения Геры вы запустили музыку в другом плеере, кнопка уйдёт плееру.
  Чтобы вернуть кнопку Гере — нажмите «Спросить» в уведомлении или перевключите тумблер.
- Распознавание речи — системное (обычно Google). На телефонах без сервисов Google может не работать.
- Микрофон гарнитуры переводит Bluetooth в режим звонка; работает не на всех устройствах.

## Структура кода

| Файл | Что делает |
|---|---|
| `AssistantService.kt` | фоновый сервис: кнопка наушников, сценарий «слушать → спросить → ответить» |
| `SpeechInput.kt` | распознавание речи |
| `LlmClient.kt` | запросы к ИИ, история диалога, tool calling |
| `WeatherTool.kt` | инструмент погоды (Open-Meteo) |
| `Speaker.kt` | озвучка ответа |
| `AudioRouting.kt` | аудиофокус и микрофон гарнитуры |
| `MainActivity.kt` | экран настроек |
| `Settings.kt` | хранение настроек |
